# ARCHIVE: Demo

## 🌑 ПРО ГРУ

Вісім років дослідницький комплекс на ізольованому острові вважався повністю покинутим. Зв'язок увірвався миттєво, а територію просто викреслили з усіх навігаційних карт. Без пояснень. Без свідків.

Усе змінюється, коли в ефірі фіксують короткий шифрований сигнал.

У ролі контрактника ви прибуваєте на острів із чітким завданням: проникнути на територію об'єкта, встановити джерело трансляції та вилучити дані. Однак перший же крок локацією показує, що стандартну операцію зірвано. Комплекс не просто функціонує — він приховує технологію, яка змінила самі закони простору.

## ⚡ КЛЮЧОВІ ОСОБЛИВОСТІ ДЕМО-ВЕРСІЇ

* **Свобода тактичного підходу**  
  Кожне завдання має кілька способів вирішення. Проникайте на об'єкти через інженерні комунікації, ліквідовуйте супротивників із тіні або вступайте у прямий вогневий контакт.

* **Просторовий «Зсув»**  
  Опануйте механіку швидкого переміщення. Перевантаження електромагнітних полів дозволяє здійснювати миттєві просторові ривки, долати укриття, заходити у фланг і розри
